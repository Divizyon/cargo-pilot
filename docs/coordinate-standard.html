Koordinat Sistemi Standardı — Cargo Pilot

TIR konteyneri ve düz konteyner için ortak eksen sistemi, origin kuralı, kapı adlandırması, standart kamera bakışları ve yükleme başlangıcı. Boyut terimleri İngilizce'dir: width, height, length.

1. Ortak eksen sistemi

Origin kuralı (her iki araç tipinde aynı): referans kapıdan içeri bakıldığında görülen uzaktaki sol-alt köşe (0, 0, 0)'dır. Referans kapı, TIR konteynerinde back door, düz konteynerde small door'dur.

Eksen Dimension Yön Aralık
x width Referans kapıdan bakıldığında sağa doğru artar 0 → width
y height Zeminden yukarı doğru artar 0 → height
z length Uzak yüzden (z = 0) referans kapıya doğru artar 0 → length

Right-handed sistem. y yukarı, z kapıya (gözlemciye) ve x gözlemcinin sağına arttığı için bu sistem right-handed'dır — Three.js / WebGL varsayılanıyla birebir aynıdır. Sahnede herhangi bir eksen aynalaması gerekmez; position=[x, y, z] doğrudan kullanılabilir.

İki small door'lu konteyner. Konteynerin iki kısa yüzünde de small door olması kuralı değiştirmez: hangisinden bakılırsa bakılsın "uzaktaki sol-alt köşe" tanımı aynı şekilde işler ve tutarlı bir sistem üretir. Referans kapı, bakılan / yükleme yapılan kapıdır ve her zaman z = length yüzünde kabul edilir.

kodda yok Kapılar liste olarak modellenir. Bir araçta aynı anda birden fazla kapı bulunabildiği için (ör. back door + iki big door) kapı bilgisi tekil bir enum değeri değil, yüz bilgisiyle birlikte bir liste olmalıdır:
doors: [{ type: 'small', face: 'z=length' }, { type: 'big', face: 'x=0' }, { type: 'top', face: 'y=height' }]

sağ / sol kapı diye bir kavram yoktur. "sağ" ve "sol" yalnızca kamera bakışlarını adlandırmak için kullanılır (bkz. bölüm 6) ve her zaman referans kapıdan bakışa göre tanımlanır. Kapılar small / big olarak sınıflanır, konumları eksen değeriyle (x = 0, z = length …) yazılır.

3. TIR konteyneri (truck container)

3.1 Isometric — referans kamera: kapı tarafı + sağ + üst

Referans kamera kapı tarafı + sağ + üst yönündedir (+z, +x, +y). Bu bakışta back door, sağ yüz ve üst yüz görünür; uzak yüz (z = 0, kabin ucu) ve sol yüz gizlidir. Origin, uzak-sol-alt köşe olduğu için bu bakışta kutunun arkasında kalır — kesikli halka ve kesikli eksen okları bunu gösterir. TIR konteynerinde ön kapı yoktur; ancak yan yüzlerde (x = 0 ve/veya x = width) big door bulunabilir.

3.2 Referans kapı görünümü — origin kuralının tanımlandığı bakış

Origin bu bakışta sol-alt köşe hizasındadır, ancak gözlemciden length kadar uzakta, z = 0 yüzü üzerindedir (kesikli halka bunu gösterir). z ekseni gözlemciye doğru artar.

4. Düz konteyner (plain container)

4.1 Isometric — small door ve big door bir arada

Düz konteynerde ön/arka/sağ/sol kapı diye bir sınıflandırma yoktur; yalnızca small door (kısa yüzde, width × height) ve big door (uzun yan yüzde, length × height) vardır. İki kısa yüzde de small door, iki uzun yüzde de big door bulunabilir. Referans olan, bakılan / yükleme yapılan small door'dur ve z = length yüzünde kabul edilir.

5. Yükleme başlangıcı

5.1 Üstten görünüm — big door origin tarafındayken başlangıç kayması

Üstten bakış: x sağa, z aşağı (referans kapıya doğru) artar. Yükleme normalde (0, 0, 0)'dan başlar. Big door origin'in bulunduğu x = 0 yüzündeyse yükleme o köşeden değil, karşı köşeden ((width, 0, 0)) başlar ve kapıya doğru ilerler.

Big door Başlangıç köşesi x doldurma yönü
yok (0, 0, 0) 0 → width
x = width yüzünde (0, 0, 0) 0 → width
x = 0 yüzünde (width, 0, 0) width → 0

Yükleme kapının bulunduğu yüzden başlamaz. Kutu kapının önüne yığılırsa operatör kendi açtığı kapıdan içeri giremez. Kapının yanında boş bırakılan bir pay yoktur — kutu duvara dayanır, değişen yalnızca hangi duvardan başlandığıdır.

Serbest köşe bırakmayan kombinasyonlar seçilemez. İki uzun yüzde birden big door, ya da z = 0 yüzünde ikinci bir small door bulunursa kapıya değmeyen köşe kalmaz; araç formu bunu engeller. Eski veriden böyle bir kayıt gelirse yükleme origin köşesinden başlar.

6. Standart kamera bakışları

Bakış Kamera yönü Görünen yüz
Kapı görünümü (referans) +z tarafından, −z yönüne bakar referans kapı — z = length
Karşı görünüm −z tarafından uzak yüz — z = 0
Sağ görünüm +x tarafından sağ yüz — x = width
Sol görünüm −x tarafından sol yüz — x = 0
Üst görünüm +y tarafından tavan — y = height
İzometrik (referans) +z, +x, +y — kapı + sağ + üst kapı yüzü, sağ yüz, tavan (origin gizli köşede kalır)

Sağ/sol, kapı görünümündeki gözlemciye göredir: gözlemcinin sağı +x, solu x = 0 tarafıdır. Üstten veya karşıdan bakışta ekranda gördüğün sol/sağ ile karıştırılmamalıdır.

7. Yerleştirme kuralları

Konu Kural
Birim Santimetre (cm). Dönüşüm yalnızca API sınırında yapılır.
Kutu pozisyonu positionX/Y/Z, kutunun origin'e en yakın köşesidir: (min x, min y, min z). Mesh merkezi değildir.
Kutu sınırları x … x + width · y … y + height · z … z + length. Hepsi araç iç ölçüsü içinde kalmalı.
Yükleme yönü Yükleme referans kapıdan yapılır: z = 0 (uzak yüz) tarafındaki kutular önce yerleşir, kapıya en yakın olanlar (z → length) en son.
Terminoloji Kod, tip, alan adı ve teknik dokümanda yalnızca width, height, length. depth, uzunluk, derinlik, w/h/d/l kullanılmaz.

8. Karara bağlanan konular

Bu belge standardı tanımlar, kodun bugünkü hâlini değil. 2 ve 3 numaralı kararlar kodda henüz uygulanmamıştır; bölüm 2 ve 5'teki kodda yok işaretli tanımlar hedefi anlatır. Bekleyen açık konu kalmadı.

  1. Small door'u olmayan konteyner — karara bağlandı, kodda uygulanıyor
    Origin geometrik bir köşedir, kapının varlığına bağlı değildir: small door olmasa da z = 0 uzak yüz, x = 0 sol yüz, y = 0 zemindir. Emsali yükleme başlangıcı kuralıdır — kapı origin köşesine değdiğinde origin taşınmaz ve konteyner döndürülmez, yalnızca başlangıç köşesi değişir.
  2. Üst kapı (top door) — karara bağlandı, kodda yok
    Üçüncü kapı tipi olarak modellenir: { type: 'top', face: 'y=height' }. Motorda üstten yükleme mantığı bulunmuyor; bölge kısıtı yalnızca LoadingType.Rear'ı kapsıyor (OPT-10).
  3. Yükleme başlangıç köşesi — karara bağlandı, kodda uygulanıyor
    Açıklık payı diye bir kavram yok. Yükleme kapının olduğu yüzden başlamaz; başlangıç köşesi kapı listesinden türetilir.

Kapı modeli geçişi (doors listesi) tamamlandığında bu bölüm ve yukarıdaki işaretler güncellenir.
