# notlar/ — geçici, tek kullanımlık notlar

Burası **serbest alandır.** Bir deneme sırasında tutulan ham çıktı, bir hipotezin karalaması, bir
oturumun yapılacaklar listesi, kıyaslarken açılan tablo — hepsi buraya. Biçim kuralı yok, gözden
geçirme yok, kalıcılık sözü yok.

Amacı, kalıcı dosyaların yarım fikirlerle dolmasını engellemek. `04-olcum-gunlugu.md`'ye bir şey
yazıldığında o artık **kayıttır**; buraya yazılan hâlâ **taslaktır**.

## Kurallar

- Dosya adı `YYYY-AA-GG-konu.md` olsun — hangi notun ne zamandan kaldığı görünsün.
- Bir not **kalıcı bilgiye dönüştüğünde**, ilgili kalıcı dosyaya taşınır ve buradaki silinir:

  | Notun içeriği | Gideceği yer |
  |---|---|
  | Ölçüm sonucu (kazanan **veya** kaybeden) | [04-olcum-gunlugu.md](../04-olcum-gunlugu.md) |
  | Kalıcı karar | [02-kararlar.md](../02-kararlar.md) |
  | Bağlayıcı kural | [01-kurallar.md](../01-kurallar.md) |
  | Yeni terim | [00-sozluk.md](../00-sozluk.md) |
  | Güncel sayı | [05-basari-karnesi.md](../05-basari-karnesi.md) |

- Buradaki hiçbir dosyaya **koddan veya kalıcı belgeden atıf verilmez.** Silinebilir olmaları
  gerekiyor; atıf alan not artık geçici değildir, yukarı taşınmalıdır.
- Eskimiş notu silmekten çekinme. Kaybolan bir şey varsa zaten yukarıya taşınmalıydı.
